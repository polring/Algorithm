# 📂 Stack / Queue

## 🧠 설명
데이터를 특정 순서로 처리하는 자료구조

---

## 📌 핵심 개념
- Stack: LIFO (후입선출)
- Queue: FIFO (선입선출)
- Deque: 양쪽 처리 가능
- java에서는 구현체로 ArrayDeque 사용 권장
---

## 🔥 자주 나오는 패턴
### stack
- 괄호 검사 
- 실행 취소 (Undo) 및 역순 출력
### Queue
- BFS 탐색 
- 시뮬레이션 및 대기열 관리

---

## ⚠️ 실수 포인트
- pop 전에 empty 체크

---

## 💡 한 줄 정리
> Stack은 역순, Queue는 순서 유지
