# 📂 Implementation (구현)

## 🧠 설명
문제의 요구사항을 그대로 코드로 옮기는 유형  
알고리즘보다는 조건 처리 / 로직 구성 / 코드 정확성이 중요한 문제  

---

### 📌 핵심 개념
* 문자열 처리 (String, StringBuilder)
* 배열 / 리스트 조작
* 조건문 & 반복문 활용
* 시뮬레이션 (문제 상황 그대로 구현)

---

### 🔥 자주 나오는 패턴
* 문자열 변환 (대소문자, 뒤집기, 치환)
* 2차원 배열 탐색
* 날짜 / 시간 계산
* 입력 조건 그대로 구현하는 문제
* 규칙 기반 시뮬레이션

---

### ⚠️ 실수 포인트
* 조건 빠뜨림 (특히 예외 케이스)
* 인덱스 오류 (Off-by-one)
* 자료형 범위 (int → long)
* 문자열 처리 실수 (공백, 대소문자)
* 요구사항을 잘못 이해함
